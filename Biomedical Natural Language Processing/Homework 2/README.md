# Description:
An assignment exploring and benchmarking prompt engineering techniques (zero-shot, few-shot, and chain-of-thought) applied to a multiple-choice medical Q&A dataset using GPT-5-mini via the Azure OpenAI API.

# Skills Demonstrated:
- Designing zero-shot instructional prompts for structured task output.
- Constructing few-shot prompts with dynamically sampled in-context examples.
- Implementing chain-of-thought prompting to elicit step-by-step reasoning before a final answer.
- Enforcing structured (JSON) output formats from an LLM and defensively parsing the results.
